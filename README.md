# 🎬 ScreenMatch - Alura Java

Projeto desenvolvido durante o curso de **Java** da Alura. A aplicação simula um sistema de gerenciamento, avaliação e persistência de dados de filmes e séries, aplicando conceitos essenciais da linguagem.

---

## 🚀 Conceitos e Aprendizados

Durante o desenvolvimento do projeto, foram explorados os seguintes temas:

### 1. Base do Java
* Sintaxe da linguagem, variáveis e tipos de dados.
* Estruturas de controle de fluxo e repetição.

### 2. Programação Orientada a Objetos (POO)
* **Classes e Objetos**: Estruturação dos dados e comportamentos.
* **Encapsulamento**: Proteção e controle de acesso aos atributos com getters/setters.
* **Herança e Polimorfismo**: Reaproveitamento de código e abstração de títulos (Filmes e Séries).

### 3. Tratamento de Exceções
* Captura e manipulação de erros com blocos `try` e `catch`.
* Garantia de estabilidade e fluxo contínuo da aplicação durante a execução.

### 4. Persistência de Dados
* Uso da biblioteca `FileWriter` para escrita de dados em arquivos de texto (`.txt` ou `.json`).
* Salvando as informações geradas pela aplicação localmente.

## 📂 Estrutura do Projeto

```text
src/
 ├── br/com/alura/screenmatch/
 │    ├── calculos/     # Lógicas de classificação e cálculo de maratona
 │    ├── excecao/      # Tratamento de exceções customizadas
 │    ├── modelos/      # Entidades principais (Filme, Serie, Titulo)
 │    └── principal/    # Classes com o método main para testes
```

## 💻 Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/gustavosilvalara/ScreenMatchAlura.git
   ```
2. Abra o projeto na sua IDE preferida.
3. Importe a pasta `src` como módulo Java.
4. Execute a classe principal presente no pacote `br.com.alura.screenmatch.principal`.
